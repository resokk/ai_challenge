# Память задачи: команда /memory

Память задачи — ваши заметки о текущем проекте: договорённости, контекст,
планы. Модель видит её в каждом запросе, пока задача активна.

## Как сделать

- Посмотреть память: `/memory`. Бот ответит `Память задачи api:` и текст или
  `Память задачи api пуста. Задать: /memory <текст>`.
- Задать или заменить: `/memory <текст>`. Весь текст после команды, вместе с
  переносами строк, заменяет память целиком. Ответ:
  `Память задачи api обновлена.`

## Пример

Вы: /memory Используем FastAPI и pytest.
Тесты лежат в tests/, запускаем /run -m pytest -q.
Бот: Память задачи api обновлена.

Вы: /memory
Бот: Память задачи api:

Используем FastAPI и pytest.
Тесты лежат в tests/, запускаем /run -m pytest -q.

## Как устроена память

- У каждой задачи своя память. При переключении задачи модель видит память
  новой задачи, а память прежней — нет.
- В списке `/tasks` задачи с памятью помечены `[память]`.
- Память не сжимается вместе с историей и не стирается командой `/reset`.
- Менять память можете только вы. Модель её не меняет, но может предложить
  текст для `/memory`, если видит, что стоит что-то запомнить.
- Дописать к памяти нельзя — только заменить целиком. Чтобы добавить пункт,
  отправьте старый текст вместе с новым.

## Что может пойти не так

- `Нет активной задачи — выберите её: /tasks <id>` — память есть только у
  задачи; сначала выберите задачу.
- `Слишком длинно: N символов при лимите 4000. Память не изменена.` — лимит
  4000 символов (значение по умолчанию). Старая память остаётся прежней.
- Очистить память полностью нельзя: `/memory` без текста только показывает
  её. Замените её коротким текстом, например `/memory -`.
