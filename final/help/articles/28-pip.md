# Установка пакетов: /pip и список установленных

`/pip` ставит пакеты в ваш личный venv или показывает, что в нём уже
установлено.

## Как сделать

- Поставить пакеты: `/pip requests` или сразу несколько —
  `/pip pytest "httpx==0.27.2" pydantic>=2,<3`.
- С дополнительными возможностями (extras): `/pip uvicorn[standard]`.
- Из файла требований проекта: `/pip -r requirements.txt`. Путь — относительно
  корня рабочей копии; нужна активная задача.
- Список установленного: `/pip` без аргументов (как `pip list --format=freeze`:
  строки `имя==версия`).

Аргументы разбираются как в командной строке: спецификацию с пробелами
возьмите в кавычки — `/pip "Django ~= 5.0"`.

## Какие спецификации допустимы

`name`, `name[extra]`, `name==1.2`, `name>=1,<2` и другие условия на версию
(`!=`, `~=`, `<=`, `>`, `<`). Всё остальное отклоняется:

- опции pip (`--index-url`, `-e`, `--upgrade`, `--force-reinstall`);
- пути (`./pkg`, `../x`, `/abs/pkg`);
- ссылки и VCS (`https://…/x.whl`, `git+https://…`).

## Пример

Вы: /pip requests
Бот: pip install requests
код выхода 0, 4.1 с
Бот: вывод pip — целиком или, если он длиннее 1 КБ, кратким изложением с
полным выводом в файле `stdout.txt`.

## Что важно знать

- Пакеты ставятся с PyPI в ваш venv. Он один на все ваши задачи.
- Установка должна уложиться в 5 минут (значение по умолчанию).
- Удалить пакет командой нельзя — такого инструмента нет. Сменить версию можно,
  поставив нужную: `/pip "requests==2.31.0"`.
- Модель тоже ставит пакеты сама (инструмент `pip_install`), когда они
  действительно нужны, и сообщает, что установила.

## Что может пойти не так

- `Ошибка: «-e» — не спецификация пакета. Допустимо: name, name[extra],
  name==1.2, name>=1,<2` — передана опция, путь или ссылка.
- `Использование: /pip -r <путь к requirements.txt>` — после `-r` нужен ровно
  один путь.
- `Ошибка: путь вне рабочей копии` или `Ошибка: файл не найден: …` — файл
  требований должен лежать в рабочей копии.
- `Ошибка: нет активной задачи с рабочей копией — выберите её: /tasks <id>` —
  для `/pip -r` нужна активная задача.
- Код выхода не 0 — смотрите stderr: обычно нет такой версии пакета или нет
  связи с PyPI.
