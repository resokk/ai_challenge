# SSH-ключ: /git ssh и добавление в GitHub

SSH-ключ нужен, чтобы бот мог клонировать ваши приватные репозитории и
отправлять изменения командой `/git push`. Бот создаёт ключ сам — вам нужно
только добавить его публичную часть в GitHub.

## Как сделать

1. Отправьте `/git ssh`. Если ключа ещё нет, бот создаст его (тип ed25519) и
   напишет `Создан новый SSH-ключ.`, затем `Публичный ключ:` и сам ключ — строку
   вида `ssh-ed25519 AAAA… devbot-<ваш telegram id>`.
2. Скопируйте ключ и добавьте его в GitHub одним из способов (ниже).
3. Повторите `/tasks <id>`, чтобы склонировать репозиторий по SSH.

Бот сам подсказывает это сообщением: `Добавьте его в GitHub: Settings → SSH and
GPG keys → New SSH key, или в репозитории Settings → Deploy keys (отметьте
Allow write access). Затем повторите /tasks <id>, чтобы клонировать по SSH.`

Если ключ уже есть, `/git ssh` просто покажет его снова — новый не создаётся.
Команда работает и без активной задачи.

## Ключ аккаунта или Deploy key

- **Ключ аккаунта** (Settings → SSH and GPG keys → New SSH key в настройках
  профиля GitHub) открывает боту все репозитории, к которым есть доступ у
  вашего аккаунта.
- **Deploy key** (Settings → Deploy keys в настройках конкретного репозитория)
  открывает только этот репозиторий. Для `/git push` обязательно отметьте
  `Allow write access`, иначе получится только клонировать.

Если боту нужен один-два репозитория, безопаснее Deploy key.

## Безопасность ключа

Приватный ключ создаётся и хранится в вашей учётной записи на сервере бота. Он
никогда не отправляется в Telegram, не пишется в лог и не попадает к модели.
В Telegram приходит только публичная часть — её показывать не страшно.

## Что может пойти не так

- `SSH-ключа нет — создайте его: /git ssh, и добавьте в GitHub.` — вы
  запустили `/git push` до создания ключа.
- `push не удался:` и `Нет доступа: добавьте ключ из /git ssh в GitHub (SSH
  keys или Deploy key с правом записи).` — ключ не добавлен в GitHub или у
  Deploy key нет права записи.
- `не удалось создать ключ: …` или `не удалось прочитать ключ: …` — сбой на
  сервере; сообщите администратору.
