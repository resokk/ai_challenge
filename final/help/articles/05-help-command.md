# Команда /help и список команд

`/help` показывает краткий список всех команд бота. Тот же список есть в меню
команд Telegram (кнопка «/» рядом с полем ввода).

## Что показывает /help

```
Команды:
/tasks — Задачи: список, переключение, создание
/memory — Память активной задачи
/git — Статус, commit, push, diff, reset, ssh
/run — Запустить скрипт или модуль: /run main.py, /run -m pytest
/pip — Установить пакеты или показать установленные
/tools — Каталог инструментов
/tool — Вызвать инструмент: /tool <name> {json}
/agents — Показать AGENTS.md (прислать — файлом .md)
/agents_clear — Удалить AGENTS.md
/context — Заполнение контекста
/summary — Краткое изложение диалога
/reset — Очистить историю чата
/help — Справка
```

В конце: `Обычные сообщения уходят модели. AGENTS.md проекта можно прислать файлом.`

Команда `/start` в список не входит: она нужна только для заявки на доступ.

## Подробная справка по командам

У двух команд есть своя подсказка. Её бот показывает, если команда вызвана с
неверными аргументами:

- `/git` с неизвестным аргументом выводит все подкоманды: `/git commit
  [сообщение]`, `/git push`, `/git diff`, `/git reset`, `/git ssh [new]`;
- `/tasks` с тремя и более аргументами выводит форматы `/tasks`,
  `/tasks <id>` и `/tasks <id> <owner/name | https://github.com/owner/name>`.

Подсказки по формату есть и у `/run`, `/pip -r` и `/tool` без аргументов.

## Как спросить подробнее

Обо всём, что касается самого бота, можно спросить модель обычным сообщением,
например: «как подключить приватный репозиторий?». Если администратор
подключил справку, модель найдёт ответ в ней. Справку можно вызвать и самому:
`/tool help__help {"question": "как подключить приватный репозиторий"}`.

## Что может пойти не так

- `/help` отвечает `Доступа нет: …` — заявка ещё не одобрена; `/help`, как и
  остальные команды, работает только после одобрения.
- Неизвестные команды (например, `/foo`) бот молча пропускает — сверьтесь со
  списком в `/help`.
