# Подключение этой справки к боту: MCP-сервер help

Справка по боту — отдельный MCP-сервер `help` с одним инструментом. Он
находит подходящие статьи справки и возвращает короткий ответ со ссылками на
них. В боте инструмент называется `help__help`.

## Как подключить

1. Установите справку (каталог `final/help`):

```bash
cd final/help
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env    # DEEPSEEK_API_KEY
```

2. Запустите сервер: `.venv/bin/python server.py`. При первом запуске он
   скачает модель эмбеддингов и построит индекс статей. Сервер слушает только
   `127.0.0.1:8770`, путь `/mcp`. Без `DEEPSEEK_API_KEY` он не стартует.
3. Добавьте сервер в `mcp.json` бота:

```json
"help": {"url": "http://127.0.0.1:8770/mcp"}
```

4. Перезапустите бота. Сервер справки должен работать к моменту запуска бота:
   MCP-серверы подключаются только при старте.

## Как проверить

- `/tools` — в каталоге есть `help__help`.
- `/tool help__help {"question": "как подключить приватный репозиторий"}` —
  ответ приходит только вам.
- Вопрос модели обычным сообщением: «как мне закоммитить изменения?» — модель
  сама вызовет `help__help` и ответит по справке.

## Как модель использует справку

В системном промпте бота сказано: на вопросы о самом боте — команды,
настройка, ошибки, «как сделать X в боте» — вызывать `help__help` с вопросом
пользователя и передавать ответ по существу, не добавляя команд, которых в нём
нет.

## Что может пойти не так

- В `/tools` нет `help__help` — сервер справки не работал при запуске бота.
  Запустите его и перезапустите бота. Без справки бот работает как обычно.
- `Ошибка: help__help не ответил за 30 с` — сервер справки не успел; ответ
  обычно занимает несколько секунд, повторите вопрос.
- Ответ начинается с `Суммаризация недоступна, найденные фрагменты справки:` —
  сервер справки не смог обратиться к DeepSeek и вернул найденные фрагменты
  статей как есть. Проверьте ключ в `final/help/.env` и связь с DeepSeek.
