# AGENTS.md: инструкции проекта для модели

AGENTS.md — ваши правила для модели: стиль кода, устройство проекта, как
запускать тесты. Бот добавляет его в каждый запрос к модели.

## Как прислать AGENTS.md

Отправьте боту файл документом — `AGENTS.md` или любой другой файл с
расширением `.md`. Бот ответит:

`AGENTS.md сохранён (1520 символов). Он будет в контексте каждого запроса.`

Новый файл заменяет прежний целиком. Бот не берёт AGENTS.md из репозитория
сам — его нужно прислать.

## Команды

- `/agents` — показать текущий текст. Если его нет:
  `AGENTS.md не задан. Пришлите файл .md, чтобы задать его.`
- `/agents_clear` — удалить. Ответ: `AGENTS.md удалён.`

## Как модель его использует

Текст передаётся модели отдельным системным сообщением с заголовком
`Инструкции проекта пользователя (AGENTS.md)`. Его правила важнее
технического стандарта бота в вопросах стиля и устройства проекта, но не
правил безопасности. AGENTS.md не сжимается вместе с историей и не стирается
командой `/reset`.

AGENTS.md один на пользователя, а не на задачу: при переключении задачи он не
меняется. Для заметок по конкретному проекту используйте память задачи
`/memory`.

## Пример AGENTS.md

```
# Правила проекта
- Python 3.12, форматирование ruff.
- Тесты в tests/, запуск: pytest -q.
- Не добавлять новые зависимости без согласования.
```

## Что может пойти не так

- `Пришлите AGENTS.md или другой файл .md.` — у файла другое расширение
  (например, `.txt`).
- `Файл слишком большой: 25000 символов при лимите 20000.` или
  `Файл слишком большой: лимит 20000 символов.` — лимит 20 000 символов
  (значение по умолчанию). Сократите файл.
- `Файл не в UTF-8.` — сохраните файл в кодировке UTF-8.
- Любой документ, который вы присылаете боту, считается попыткой задать
  AGENTS.md. Передать модели другой файл так нельзя — положите его в
  репозиторий.
