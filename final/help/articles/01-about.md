# Что умеет бот и для кого он

Бот — ассистент Python-разработчика в Telegram. Он отвечает через языковую
модель DeepSeek, работает с вашим репозиторием на GitHub, запускает ваш код и
сам следит за длиной диалога.

## Что умеет бот

- Отвечает на вопросы о Python и о коде вашего проекта. Прежде чем отвечать
  про проект, модель сама смотрит файлы рабочей копии инструментами
  `list_files`, `search_files`, `python_outline` и `read_file`.
- Правит файлы проекта по вашей просьбе (`edit_file`, `write_file`).
- Клонирует репозиторий задачи с GitHub, показывает статус рабочей копии,
  делает ревью изменений, коммитит и пушит — команда `/git`.
- Ставит пакеты в ваш личный venv (`/pip`) и запускает скрипты и тесты (`/run`).
- Узнаёт сведения о пакетах на PyPI, даёт ссылки на документацию Python и
  текущее время.
- Помнит заметки по проекту (`/memory`) и инструкции проекта из файла AGENTS.md.
- Сам сжимает длинную историю, чтобы диалог не упирался в лимит контекста.
- Может вызывать дополнительные инструменты, которые подключил администратор
  (MCP-серверы), например эту справку.

## Для кого он

Для Python-разработчика, который хочет обсуждать и править свой проект прямо из
Telegram: найти и исправить ошибку, написать функцию с тестом, посмотреть, что
изменилось, и закоммитить. Пользоваться ботом могут только те, кого одобрил
администратор.

## Чего бот не делает

- Не делает принудительный push: `--force` не поддерживается.
- Не удаляет файлы через инструменты модели — удаления в файловых
  инструментах нет.
- Модель сама не коммитит и не пушит: это делаете вы командами `/git commit`
  и `/git push`.
- Работает только с репозиториями GitHub: `owner/name` или
  `https://github.com/owner/name`.
- Обрабатывает только текстовые сообщения и файлы `.md` (как AGENTS.md);
  фото и голосовые сообщения бот не обрабатывает.

## С чего начать

Отправьте `/start` и дождитесь одобрения администратора. Список команд
покажет `/help`.
