# Как модель читает и ищет код в проекте

Модель не знает содержимого вашего проекта заранее. Прежде чем отвечать про
код, она сама смотрит файлы рабочей копии активной задачи с помощью
инструментов.

## Какие инструменты есть у модели

- `list_files` — список файлов проекта с размерами. Параметры: `path`
  (каталог, по умолчанию `.`), `glob` (шаблон, например `**/*.py`),
  `max_results` (по умолчанию 200). Если файлов больше — пометка
  `[показано 200 из 950]`.
- `search_files` — поиск строки или регулярного выражения по всем текстовым
  файлам. Результаты вида `path:line: строка`, сгруппированы по файлам, в конце
  `Совпадений: N`. Параметры: `query`, `regex`, `glob`, `case_sensitive`,
  `max_results` (по умолчанию 100).
- `python_outline` — структура Python-файла: импорты, классы, методы и
  функции с номерами строк, сигнатурами и первой строкой docstring. Помогает
  разобраться в файле, не читая его целиком.
- `read_file` — содержимое файла с номерами строк, можно запросить диапазон
  (`start_line`, `end_line`). Длинный файл обрезается с подсказкой, например
  `[обрезано: показаны строки 1-420 из 900; дальше запросите start_line=421]`.

Все инструменты учитывают `.gitignore` и не показывают каталог `.git`.

## Как это выглядит для вас

Пока модель работает, бот показывает статус вроде `вызываю search_files…`.
Результаты инструментов вам не присылаются — вы получаете только итоговый
ответ модели. За один ответ модель может сделать до 8 шагов с инструментами
(значение по умолчанию).

## Как спрашивать

- Называйте файл, функцию или текст ошибки: «почему `parse_config` падает на
  пустом файле?».
- Просите конкретное: «найди все вызовы `requests.get` и перечисли файлы».
- Для больших проектов подскажите, где искать: «смотри в каталоге `app/api`».

Вы можете вызвать те же инструменты сами, например
`/tool search_files {"query": "def main"}` — результат придёт только вам.

## Что может пойти не так

- `нет активной задачи с рабочей копией — выберите её: /tasks <id>` — без
  активной задачи модель не видит файлов.
- `Совпадений нет.` или `Файлов не найдено.` — проверьте шаблон `glob` и
  написание.
- Модель отвечает, не посмотрев файлы, — попросите прямо: «сначала прочитай
  файл app/main.py».
