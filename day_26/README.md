# День 26: веб-чат с локальной моделью

Лёгкий веб-чат с моделью через Ollama. Только стандартная библиотека Python, без зависимостей.

```bash
ollama pull qwen2.5-coder:7b
python app.py            # http://127.0.0.1:8000
python app.py --model qwen2.5:7b --port 8080 --num-ctx 16384
```

- **Ответ стримится** по мере генерации (`/api/chat` Ollama, `stream: true`).
- **История — только в памяти процесса**: словарь «id сессии → сообщения». Перезапуск сервера её стирает.
  Id сессии живёт в `sessionStorage` вкладки: перезагрузка страницы продолжает диалог, новая вкладка начинает новый.
  «Новый чат» очищает историю на сервере.
- **Контекст** по умолчанию 32768 токенов (`num_ctx`, максимум для qwen2.5-coder). Вся история уходит в модель целиком;
  если она длиннее окна, Ollama обрежет начало.
- Ход попадает в историю только после полного ответа: если клиент отключился или Ollama вернула ошибку, ход не сохраняется.
- Сервер слушает только `127.0.0.1`. Сообщение — до 20 000 символов, id сессии должен быть UUID.

| файл | что делает |
|---|---|
| `app.py` | HTTP-сервер: страница, `POST /api/chat` (стрим ответа), `GET /api/history`, `POST /api/reset` |
| `index.html` | страница чата: стриминг через `fetch` + `ReadableStream`, светлая и тёмная темы |
